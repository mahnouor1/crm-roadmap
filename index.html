AI Outreach CRM

From lead verification to AI-personalized email outreach, built as real infrastructure.

Roadmap

Five phases, tracked as they're actually built — not as a plan.

  1. 01

    Lead Pipeline

    Done
    • CSV / XLSX import
    • Normalization
    • Deduplication
    • ICP / industry qualification
    • Website validation
    • MX checks
    • SMTP mailbox verification
    • Qualification states
  2. 02

    CRM

    Done
    • Leads
    • Campaigns
    • ICP configuration
    • Lead assignment
    • Lead activity / status
    • Qualification evidence
    • Campaign eligibility

    CRM is the source of truth.

  3. 03

    Outreach Engine

    Done
    • Atomic lead dispatch
    • Lead claiming
    • Duplicate-dispatch protection
    • Stale claim recovery
    • Campaign-based assignment
    • SENT status tracking
    • Idempotent webhook handling
  4. 04

    AI Email Workflow

    Done

    CRM → n8n → Gemini → Email → CRM

    • CRM selects eligible leads
    • n8n orchestrates execution
    • Gemini generates personalized openings
    • Email infrastructure sends
    • CRM records the result

    n8n is the orchestration layer — not the database.

  5. 05

    Production Deployment

    Done
    • Production CRM deployed
    • Isolated PM2 process
    • Dedicated port
    • Caddy reverse proxy
    • HTTPS
    • Basic authentication on CRM pages
    • Protected dispatch / webhook endpoints
    • Existing applications isolated from deployment
